# 准奏 · 三省六部

- 中书：seat `default:oak_chair`
- 门下：副署（error=0）
- 六部：6/6 画押
- 礼部出处：https://ce-pre.gtemc.cn/zh-Hans/configuration/block/behaviors/seat_block

## 准予施行的 YAML
```yaml
blocks:
  default:oak_chair:
    state:
      auto_state: note_block
    behavior:
      type: seat_block
      seats:
        - 0,0,0
items:
  default:oak_chair:
    material: paper
    behavior:
      type: block_item
      block: default:oak_chair
```
